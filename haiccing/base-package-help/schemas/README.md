# schemas/

The package's schemas, each named by its URI, `haiccing/base-package-help/<name>`, registered when it is deployed.

- `annotate-answer.json`: `help/annotate`'s answer
  (`haiccing.basePackageHelp.annotateAnswer`): `help`, `does`, `door`,
  `arguments`, `run`, `more`, and `answer`, the same in natural
  language, a line each. The help viewer asks for its help typed as it.
